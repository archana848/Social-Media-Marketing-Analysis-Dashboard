# Social-Media-Marketing-Analysis-Dashboard

## Project Overview
This Power BI dashboard analyzes social media marketing campaign performance across different platforms, regions, and content types. The dashboard provides insights into engagement, conversions, follower growth, and overall campaign performance.

---

## Tools Used
- Power BI
- Excel
- DAX

---

## Dataset Details
The dataset includes:
- Platform details
- Content types
- Revenue
- Clicks
- Engagement rate
- Conversion rate
- Followers count
- Regional performance
- Monthly trends

---

## Dashboard Features
- KPI Cards for Revenue, Clicks, Engagement, Conversion & Followers
- Platform Performance Analysis
- Content Type Distribution
- Monthly Trend Analysis
- Region-wise Performance
- Followers Growth Analysis
- Interactive Slicers for filtering data

---

## Key Insights
- YouTube shows the highest engagement and conversion performance.
- Video and Carousel content types generate the best audience interaction.
- Total followers reached 11M with strong overall campaign performance.
